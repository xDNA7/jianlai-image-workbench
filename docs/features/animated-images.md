# 动图生成增量

用户授权：在现有生图流程接入动图、自动推荐参数，测试后发布生产。

## 行为与边界

- 复用现有对话、计划卡、确认生成、幂等任务、计费与图片画廊。
- GIF 意图默认推荐 4 fps、3 秒、12 帧；明确时长限制推荐为 1–6 秒，最多 24 帧。调整必须在确认前说明。
- 使用精确的支持动图模型，不向静态模型降级；不传强制 PNG 输出参数。
- 验证实际格式、帧数、时长、尺寸与解码资源；保留原始 GIF，列表用静态预览，详情与下载用原文件。
- 静态返回或参数偏差如实提示，已交付结果沿现有按张计费，不自动重试或按帧计费。
- 不新增页面、时间线、MCP、视频权限、GIF 参考图输入或数据库迁移。

此前逐档单次实测不构成硬上限或稳定成功率；推荐范围用于控制画质和复杂度。

## 验收与回退

覆盖意图与否定、默认/明确/非法参数、服务端归一、幂等兼容、真实 GIF 完整性与解码上限、原文件扩展名、静态降级提示、计划确认、画廊详情下载，以及现有生图回归。

发布前保留当前后端和前端 release 指针；校验同一被测产物。生产观察至少 120 秒、6 轮，健康和公开生图可访问、视频权限仍生效、静态文件哈希一致，服务无意外重启且无新增 ERROR/非预期 5xx。任一关键检查失败停止发布并回切应用；沿用当前数据库，不用旧快照覆盖新写入。

实施及测试状态见 STATUS；失败证据不替换成成功记录，未执行检查明确保留。
