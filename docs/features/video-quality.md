# 视频公开、画风与生成质量优化

用户明确授权公开视频功能、默认15秒分镜、收集对话画风并在卡片选择、优化真人肤质与查证供应商参数，同时清理确实无用的引用和依赖，沿既有测试上线授权。

- 移除独立内部口令门槛及其UI/会话状态；普通账户归属、Origin、余额确认、幂等与私有媒体鉴权继续保留。
- 默认15秒，明确时长仍尊重4–15秒，超过15秒继续压缩与提示；不新增多任务剪辑。
- 现有分镜卡加入画风选择，支持用户列出的七种方向、自定义和未指定；对话明确画风优先，确认前可编辑。
- 按实际供应商文档优化分镜与发送前提示词，真人方向强调自然肤质、光线与合理镜头；动画方向不强加真人纹理。禁止虚构API支持参数或承诺肤质必然改善。
- 不增加自动付费中间生成、超分、磨皮或第三方图片上传流程。质量参数只接入已证实兼容当前网关的字段，费用变化在确认卡显示。用户确认网关不支持2K，因此全链路仅保留768P。
- 清理限定为本轮移除的内部口令链路与查证无引用的依赖，保留现有Nomi改编许可与真实镜头操作，不扩大架构迁移。

验收：公开视频入口/接口、越权媒体404、Origin拒绝、默认15秒与显式时长、画风对话继承与卡片切换、编译后的供应商请求、真人/动画提示词隔离、未知接单不重发及账务/恢复回归。类型/lint/单测/构建/浏览器/隔离PG、公开扫描与CI通过后同产物发布。

发布保留原release与PG备份，独立恢复核验；代码回切继续当前数据库。观察至少120秒6轮健康、公开生图和视频入口、私有媒体归属、静态哈希、二进制一致及0意外重启/新增ERROR/非预期5xx；关键失败停止切换并回退应用。

## 资料与适用边界

- 官方 H3 V2 参数：https://platform.minimax.io/docs/api-reference/video-generation-v2-create
- 官方 H3 场景提示词：https://platform.minimax.io/docs/guides/video-prompt
- 官方支持主体/动作/镜头/画风等多模态提示；真人纹理、柔光与连续性要求是本项目的提示词策略，不是供应商保证。
- 官方H3包含2K能力，但本项目用户明确自己的网关不支持，故仅768P。prompt_optimizer/fast_pretreatment属于旧版；H3-Max专属prompt_expansion_mode不能用于当前H3；不传文档未证实的negative_prompt、seed、guidance或fps。
- 清晰自然的首帧有助于保留材质；油画首帧无法靠输出分辨率保证修复。首帧可选，不增加自动付费重绘。
