# 剑来生图工作台 PRD

## 用户和场景

- 用户：需要通过文字、参考图和方案卡完成生图、修图和视频生成的个人用户；管理员负责审核、额度、模板和任务处理。
- 触发场景：用户打开 `/jianlai/`，输入想法或上传参考图，确认方案后生成；随后查看作品、模板、视频或任务状态。
- 成功任务：用户能在同一会话中完成输入、确认、生成、恢复和下载，并在移动端与桌面端获得一致结果。

## 本期结果

- [ ] React Router Framework Mode SPA 替换现有前端路由，保留 `/jianlai/`、管理入口和旧 UI 回滚入口。
- [ ] Rust/Axum 分层服务使用 SQLx + PostgreSQL，完整保留生成、编辑、作品、模板、视频、额度、审核、管理员和任务恢复。
- [ ] SQLite 脱敏影子库、PostgreSQL 双读校验、备份/恢复和回滚证据完成后才切生产。
- [ ] PWA manifest、图标、安全区、动态视口和更新提示可用；核心流程保持在线，不做离线写入。

## 非目标

- 不引入微服务、Redis、第二套完整 UI 组件库或实时协作。
- 不在浏览器保存余额、任务终态或媒体授权；本地只保存明确允许的草稿/界面偏好。
- 不在迁移完成前删除 Rust/SQLite 旧发布、旧静态资源、备份或 Angie 回滚配置。

## 成功标准

- 功能：现有 API 和业务矩阵逐项通过，任务状态、额度不变量、账户隔离和管理员审计无回归。
- 数据：SQLite 到 PostgreSQL 的记录数、关键字段、额度、任务、媒体引用和时间线可核对；差异可定位且可回滚。
- 体验：390x844 和桌面视口无重叠，键盘、长文本、空/错/加载/权限拒绝、reduced-motion 均有验收证据。
- 发布：本机构建产物有 SHA，Angie 配置检查、systemd 健康检查、生产 smoke 和失败回滚均可执行。
