# 剑来生图工作台计划

更新日期：2026-11-08
状态：本轮重构与 PostgreSQL 主库切换已完成并上线；本文件记录已确认范围与验收边界，
后续增量在此基础上更新，不重开已完成项。

## 已确认目标

- 用户：通过文字、参考图与方案卡完成生图、修图和视频生成的个人用户；管理员负责
  审核、额度、模板和任务处理。
- 核心结果：单会话内完成输入、确认、生成、恢复和下载，移动端与桌面端结果一致。
- 前端：React 19 + React Router Framework Mode + Vite + Tailwind CSS 4，
  BoardUI / React Aria 为 AI 工作台主 UI 体系。
- 后端：Rust + Axum + Tokio 模块化单体，分层 routes → handlers → services →
  repositories。
- 数据：SQLx + PostgreSQL 为主读写；SQLite 仅在迁移与回滚期间保留。
- 媒体：OSS 保存原图、预览、模板与视频；Angie 托管静态资源并代理 API。
- 入口：沿用 `/jianlai/` basename 与随机管理入口；根域名不承载产品页面。

## 非目标

- 不新增公开取消 API、第三方支付网关回调、完整接口错误协议改版或多实例调度；
  这些属于新产品范围，不得写成已实现功能。
- 不引入 Redis、独立队列或微服务；单实例 lease 已满足当前并发模型。
- 不删除原始 SQLite 数据与旧发行版，回切材料保留。
- 不另建第二套主 UI 组件体系。

## 架构与数据边界

浏览器 → React Router 页面 → TanStack Query / API client → Axum handler →
service → SQLx repository / PostgreSQL；生成媒体经校验后上传 OSS，以任务状态
和授权 URL 返回。SSE 只传任务与对话事件，不把凭据或余额写入浏览器。

迁移路径：SQLite 导出 → 脱敏 fixture → PostgreSQL 幂等导入 → 双读差异报告 →
最终备份与在途任务处理 → Angie / systemd 切换。任一校验、健康检查或恢复演练
失败即回到旧 Rust / SQLite 发行版。应用回切不得覆盖新账本。

## 验收与门禁

- 前端：typecheck / lint / 单测 / build；Playwright 覆盖桌面、390×844、键盘、
  焦点、Escape、遮罩、背景锁、触摸和下载。
- 后端：fmt / clippy / 单测；SQL 目录与精确 release 二进制全量 HTTP 回归。
- 数据：账本事务、并发锁、幂等、部分交付、失败退款、导入回滚与
 真实 `pg_dump` / `pg_restore` 演练。
- 公开仓库：push 与 PR 触发 Actions；本地推送前执行公开检查、密钥扫描与
  图片人工复核。源码、构建产物与生产部署的证据分开记录。

## 发布与回滚

发布说明写清提交 SHA、产物 SHA-256、依赖与工具链版本、数据库迁移状态、
观察窗口与回滚命令。可回滚对象包括前端发行版、后端二进制与数据库快照；
回滚动作与执行责任在切换前明确，不用页面 200 或构建成功代替业务结果。

## 备份

源码在公开仓库之外，另有私有 OSS 加密历史（每周保留 3 代），与集中私有备份
仓库相互独立。生产数据库快照、媒体与部署资产按项目规范执行，恢复演练结果
单独记录。

## 待确认

- 后续功能增量（模板体系扩展、批量任务、多实例调度）尚未确认范围，
  在单独确认前不实现。

## 2026-11-08 实现收敛与受控发布

用户已授权本次审查优化、完整测试和上线。保留现有界面、功能、API 路径、
计费、权限和 PostgreSQL 数据；不换框架、不增加服务或付费供应商调用。

- 前端核对旧工作台功能对等后移除当前构建中的 legacy 入口；历史发行版保留。
- API 数据由 Query 唯一持有，聊天流与临时交互继续使用本地状态。
- 完善已有 OpenAPI/生成类型与漂移检查；固定实际构建运行时，验证后删除无用依赖。
- 收敛重复按钮适配，保持已有尺寸、样式、可访问性和行为。
- 后端优化现有兼容边界与可观测性，不以全量异步重写替代本次最小化目标；
  保留回切能力和账本锁，数据库 schema 与账务语义不变。
- 将生产 API 切到受控 release/current/shared 产物，静态前端沿用原子发布；
  不恢复旧数据库快照覆盖新写入，不将旧工作区修改自动带入新源码。

验收：前端冻结安装、契约检查、类型/lint/单测/构建、桌面与手机浏览器回归；
Rust fmt/clippy/单测/release、同一 release 二进制隔离 PG/HTTP 回归；公开边界与
产物扫描。生产切换先关闭新增任务入口并排空，备份与独立恢复核验后重启。

发布基线为当前静态 release、运行二进制和 PostgreSQL 主库。发布后至少观察
120 秒且完成 5 次健康与静态哈希核验；健康不为 Rust/PG/ok、服务重启、关键
静态哈希持续不一致或任一非预期 5xx 即停止发布并回切代码/代理配置。账务与
媒体权限在隔离测试验证，公网只做无付费 smoke；旧代码回切继续使用当前 PG。
详细命令、产物哈希、实际结果与回切指针在私有发布证据及项目 STATUS 维护。
